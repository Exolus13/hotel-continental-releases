# Hotel Continental - Descargas

Repositorio publico para distribuir versiones de Hotel Continental.

Launcher para descargar e iniciar el juego: HotelContinentalLauncher.exe.

Paquete del juego que se adjunta a cada release: HotelContinental-Windows.zip.

Abre el launcher para instalar el juego y comprobar futuras actualizaciones.
